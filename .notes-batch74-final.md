# Batch 74 — final state (2026-08-19 05:57 UTC)

## Root causes found & fixed (THE BIG ONES)
1. **model field missing bug**: server/index.ts /api/chat previously sent `body` (client payload WITHOUT `model`) as the upstream request body; the merged `{...body, model: modelId}` was only used for a log header. All providers (Nvidia most visible) returned 400 "model field is required". FIXED: `upstreamBody = { ...(body ?? {}), model: modelId }` is now the real request body.
2. **Auth header bug**: PROVIDERS map had `bare: true` for groq/mistral/opencode, sending API key WITHOUT `Bearer ` prefix → Groq 401 "Invalid API Key" through proxy while direct curl (with Bearer) worked. FIXED: all providers now send `Bearer ${key}`; removed bare field.
3. **Streaming hang**: server/index.ts SSE pump had no inactivity watchdog — providers (e.g. Nvidia mini models) can stall or never send [DONE] → cursor blinks forever, stop stuck. FIXED: 30s idle watchdog + res.on("close") → reader.cancel() (mirrors aiProxy.ts fix).
